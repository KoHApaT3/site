# Programming Tutor (Dart, Python, JavaScript)

Мобильное приложение на Expo/React Native для изучения языков программирования: Dart, Python, JavaScript. Содержит уроки, примеры кода и квизы. Прогресс сохраняется локально.

## Запуск

1. Установите зависимости:

```bash
npm install
```

2. Запустите приложение:

```bash
npm run start
```

Откройте Expo Go на устройстве или эмулятор.
